# Changelog

All dates are check dates of the vendor pages.

## 1.0.0 - 2026-11-16

- First release: 11 tools (Roam, Geovo, GFaker, Mirage, Locus, Roam Control,
  Tenorshare iAnyGo, iMyFone AnyTo, iToolab AnyGo, Dr.Fone Virtual Location,
  3uTools).
- `data/tools.csv` and `data/tools.json`: one row per tool.
- `data/facts.csv`: the same values in long format, one fact per row with its
  source URLs and check date.
- `data/sources.csv`: every source URL and what it supports.
- Vendor pages re-read on 2026-11-16. GFaker blocked automated re-fetching
  that day; its values are as recorded from its pages on the Roam comparison
  page the same day.
